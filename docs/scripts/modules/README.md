# Redis Module Scripting

Redis module scripting lets developers use Lua scripts to interact with Redis modules, extending Redis's functionality. Redis modules provide additional features and data structures that can be operated on through Lua scripts.

## RedisGraph

RedisGraph is a Redis module for graph database functionality. It allows users to store and query graph data in Redis.

- **Cypher query language overview**  
  Cypher is the query language of RedisGraph, used for querying and operating on graph data. The Cypher language is designed to be intuitive, similar to SQL, but optimized for graph data.

- **Basic Cypher query commands**  
  An introduction to the commonly used Cypher query commands in RedisGraph, including creating graphs and querying nodes and relationships.

## RedisJSON

RedisJSON is a Redis module for handling JSON data in Redis. It allows users to store, query, and modify data in JSON format.

- **JSONPath query language overview**  
  JSONPath is the query language used by RedisJSON, used for performing complex queries and operations on JSON data. The JSONPath language is similar to XPath, but designed for JSON data.

- **Basic JSONPath query commands**  
  An introduction to the commonly used JSONPath query commands in RedisJSON, including creating, querying, and modifying JSON data.
