# Medis

Medis 是一款面向开发者的 Redis 桌面 GUI 客户端（最初为 macOS 应用，后提供跨平台版本与 Web 版），用于浏览和管理 Redis 数据，是命令行之外排查数据问题的常用工具。

## 主要功能

- **键浏览与搜索**：按模式（如 `user:*`）扫描键，查看类型、TTL 与内存占用；
- **数据查看与编辑**：String/Hash/List/Set/ZSet/Stream 的内容展示与在线编辑；
- **实时监控**：查看命令统计、内存与连接信息；
- **多环境管理**：保存多个连接配置（本地、测试、生产），支持 SSH 隧道连接内网实例；
- **集群支持**：可连接 Redis Cluster 节点。

## 使用场景

- 本地开发时快速确认数据写入是否符合预期；
- 排查问题时按模式查看键、检查 TTL 设置是否遗漏；
- 向非开发同事演示数据结构时提供直观视图。

## 替代工具

| 工具 | 平台 | 特点 |
| --- | --- | --- |
| RedisInsight | 官方，跨平台 + Web | 免费，功能最全（慢查询分析、集群视图） |
| Another Redis Desktop Manager | 开源，跨平台 | 轻量、活跃维护 |
| Medis | macOS/Windows/Web | 界面简洁，macOS 体验好 |

## 注意事项

- **生产环境谨慎使用**：GUI 的批量删除、重命名等操作不可撤销，建议只读账号连接生产库；
- **大键展示**：包含几十万元素的集合在 GUI 中全量渲染会卡顿，优先用 `SCAN` 方式查看（Medis 支持）；
- **SSH 隧道**：连接内网 Redis 时建议通过 SSH 隧道，不要把 Redis 端口直接暴露公网。
