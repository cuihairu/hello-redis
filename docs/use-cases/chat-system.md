# 聊天系统

Redis 在聊天系统里承担两块职责：Pub/Sub 做实时消息推送，ZSET 或 List 做历史消息存储。两者拼起来构成一个可用的聊天骨架。

## 实时推送

Pub/Sub 把消息广播给频道的所有订阅者，消费者在线就能收到。Pub/Sub 的语义是发后即弃：消息发出后不保存，消费者不在线就收不到，也不保证可靠投递。在线状态用 String 或 Hash 维护，键带 TTL，断线自动清理。

## 消息存储

- 会话消息按时间序存 ZSET，分数为时间戳，`ZRANGE` 取最近 N 条，天然有序；
- 需要严格顺序和大容量时用 Streams，一条条追加，支持消费组与确认。
