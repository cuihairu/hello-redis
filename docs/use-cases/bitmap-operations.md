# 位统计

位图（Bitmap）并非独立的数据类型，而是以字符串（String）为载体、按位（bit）进行操作的命令集合。它在需要保存大量布尔状态时极其省内存：1000 万个用户的签到状态只占用约 1.2 MB。

## 核心命令

```bash
# 设置/读取第 N 位（N 从 0 开始）
SETBIT dau:2024-06-03 1001 1
GETBIT dau:2024-06-03 1001     # 1

# 统计置位数量
BITCOUNT dau:2024-06-03

# 统计置位数量（带字节区间，可加速部分统计）
BITCOUNT dau:2024-06-03 0 -1 BYTE
```

## 多日位图的聚合运算

每天一个位图键，可以做跨天的逻辑运算：

```bash
SETBIT dau:2024-06-03 1001 1
SETBIT dau:2024-06-04 1001 1
SETBIT dau:2024-06-04 1002 1

# AND：两天都活跃的用户
BITOP AND dau:both dau:2024-06-03 dau:2024-06-04
BITCOUNT dau:both            # 1（用户 1001）

# OR：两天任一活跃的用户
BITOP OR dau:any dau:2024-06-03 dau:2024-06-04
BITCOUNT dau:any             # 2

# NOT：取反（注意按字节取反，结果只在指定字节范围内有效）
BITOP NOT dau:not dau:2024-06-03
```

## BITPOS 与 BITFIELD

```bash
# 第一个置位的位置
BITPOS dau:2024-06-03 1       # 1001

# 从指定位置开始找
BITPOS dau:2024-06-03 1 125   # 找第 125 字节之后的第一个 1

# 一次读取多个位段（unsigned 8 位整数）
BITFIELD dau:2024-06-03 GET u8 1001
```

## 典型应用

- **日活（DAU）统计**：`SETBIT dau:{日期} {用户ID} 1`，当天人数用 `BITCOUNT`，无需去重集合。
- **连续活跃天数**：把一周的 7 个位图 `BITOP AND` 后 `BITCOUNT` 即可得到连续 7 天活跃人数。
- **用户留存**：`BITOP AND dau:day1 dau:day2` 的结果数量就是留存人数。
- **排行榜前 N 名的标记**：把榜单结果标记到固定位图上，用于快速判断"是否进入热门"。

## 注意事项

- 位偏移是基于字节串的，单个位图键理论上限为 512 MB（2^32 位）；实际按天/按月建键即可。
- 位偏移过大时会创建很大的字符串（中间空字节），如 `SETBIT k 100000000 1` 会占用约 12.5 MB，务必按合理维度拆分键。
- 用户 ID 不连续时（如雪花 ID），不要直接把 ID 当偏移，可以用 `MOD` 取模或改用 HyperLogLog 做基数统计。
