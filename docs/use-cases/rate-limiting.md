# 限流

限流保护服务不被突发流量打垮：超过阈值的请求快速失败或排队。Redis 的原子命令让计数与判断一次完成，是限流计数器的常用实现。

## 四种策略

| 策略 | 实现 | 特点 |
| --- | --- | --- |
| 固定窗口 | `INCR` + 键过期 | 实现最简单，窗口边界可能突刺两倍流量 |
| 滑动窗口 | ZSET 记录请求时间戳 | 平滑但内存随请求量线性增长 |
| 漏桶 | ZSET 或 List 按速率消费 | 输出速率恒定，无法应对突发 |
| 令牌桶 | Lua 脚本补令牌 | 允许一定突发，控制平均速率 |
