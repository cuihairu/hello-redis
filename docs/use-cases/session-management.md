# 会话管理

Web 集群下会话不能只存在单台应用服务器的内存里：负载均衡把请求分到另一台机器就会丢失登录态。把会话集中存到 Redis，所有应用实例共享同一份会话数据，再用过期机制自动清理失效会话。

## 核心做法

- 用 Hash 存会话字段（用户 ID、昵称、权限），单字段读写，不必整存整取；
- 会话键用足够长的随机串（如 UUID），避免被猜测和遍历；
- 会话键必须带 TTL：30 分钟无操作自动失效，每次活跃请求重置 TTL（滑动续期）；
- 登录时生成新会话 ID，防会话固定攻击；密码等敏感信息不落会话。
